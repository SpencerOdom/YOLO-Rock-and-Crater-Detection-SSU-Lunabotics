🌕🚀 Lunar Rover Rock & Crater Detection
By: Spencer Odom • Jordan Nakamoto • Logan Puntuos

📜 Description
We’re tasked with creating the object detection system for SSU’s Lunar Rover for the NASA Lunabotics Competition.
Our system detects rocks 🪨 and craters 🕳️ on the lunar surface in real time, enabling autonomous navigation and hazard avoidance.

📂 Dataset
We created our own AI-generated dataset to simulate realistic lunar terrain conditions.
📦 Kaggle Dataset: 🔗 https://kaggle.com/datasets/7c6e4acd53da5a82ed374e664c57713d09680831618bf095d175c1ac9fadebd7

🏆 NASA Lunabotics Competition
The NASA Lunabotics Competition challenges teams to design autonomous lunar rovers capable of mining and transporting resources.
Our detection system is designed to keep the rover safe while it navigates rugged, hazardous lunar terrain.
